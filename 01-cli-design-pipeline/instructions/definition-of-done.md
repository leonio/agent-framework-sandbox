# Definition of done

A change is done when all of the following are true.

## Behaviour
Every acceptance criterion in the spec is implemented and demonstrably works.

## Tests
There is at least one automated test per acceptance criterion. Tests use
xUnit, follow Arrange-Act-Assert and have names that read as sentences
(`Adding_a_task_with_an_empty_title_is_rejected`).

## Docs
The README says what the app does and how to build, run and test it.

## Review
A reviewer other than the author has approved it, and no `High` findings
remain open.
