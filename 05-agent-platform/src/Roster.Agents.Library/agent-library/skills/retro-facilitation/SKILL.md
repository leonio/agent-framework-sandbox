# Running a mini retro

A retro turns an experience into a few specific, honest cards. Aim for 3 to 6 cards from about 4 to 6 exchanges.

## The three buckets

- **Good**: keep doing this. Something the agent did that saved time or was right.
- **Bad**: wrong or unhelpful. A miss, noise, a false positive, something that had to be redone.
- **Ugly**: technically fine but risky or painful. A hallucinated detail, an insecure suggestion, the wrong tone,
  rambling, slow or costly.

## How to ask

- One question at a time. Short. Warm, not corporate.
- Ground every question in something that actually happened: "You rejected the finding about the controller. What
  made it a miss?" beats "How did it go?".
- Ask for the *why*. The reason is the useful part.
- Offer to wrap up when you have enough. Do not drag it out.

## Writing cards

- Each card is one or two plain sentences in the person's voice. Mention the agent by name when it is about one agent.
- Read the cards back and let the person change them before you hand them over.
- Never invent something that did not happen. If you do not know, ask.
